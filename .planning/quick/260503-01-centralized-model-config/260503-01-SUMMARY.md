# Quick Task 260503-01: Centralized AI Model Config

## What was done

Created `models.config.json` at the project root as a single source of truth for all AI model definitions. Both the frontend and backend now derive their model data from this file.

## Files changed

- **Created** `clanker_poker/models.config.json` — 4 model entries, each with: id, name, org, color, deck, litellmModel, stake
- **Updated** `clanker_poker/lib/constants.ts` — imports JSON; derives MODELS, ModelId, STAKE_MAP from it
- **Updated** `clanker_poker/backend/app/config.py` — `player_models` defaults from JSON via `Field(default_factory=_default_player_models)`; PLAYER_MODELS env var still overrides
- **Updated** `clanker_poker/backend/.env.example` — PLAYER_MODELS line commented out, now documents the JSON as the source of defaults

## Result

Adding, removing, or changing a model now requires editing only `models.config.json`. Frontend UI metadata and backend LiteLLM strings stay in sync automatically.
