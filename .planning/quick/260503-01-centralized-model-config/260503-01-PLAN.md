# Quick Task 260503-01: Centralized AI Model Config

## Problem

Model definitions are split across two files:
- `lib/constants.ts` — UI metadata (id, name, org, color, deck, stake)
- `backend/app/config.py` — LiteLLM model strings (player_models)

Adding/changing a model requires editing both files in sync.

## Solution

Create `models.config.json` at the project root as the single source of truth.

## Tasks

### Task 1: Create models.config.json
- File: `clanker_poker/models.config.json`
- Contains: all model fields (id, name, org, color, deck, litellmModel, stake)

### Task 2: Update constants.ts
- Import JSON, derive MODELS array, ModelId type, STAKE_MAP from it
- Remove hardcoded values

### Task 3: Update config.py
- Read defaults from JSON via `Field(default_factory=...)`
- PLAYER_MODELS env var still overrides

### Task 4: Update .env.example
- Add comment pointing to models.config.json
