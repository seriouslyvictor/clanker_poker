# Quick Task 260509-01: Rich Logging + LLM Budget

## Objective

Two concerns in one pass:

1. **Logging** — the terminal shows almost nothing useful. Add colored, structured log output using `rich` (already installed at v15.0.0) so the game is fully observable at the server terminal: session roster, hand boundaries, phase transitions, every player action, and LLM call/response/fallback events.

2. **LLM budget** — `max_tokens=300` is too tight; DeepSeek is having its JSON fence truncated mid-sentence. Raise to 5000. Also remove the `MAX_SYSTEM_TOKENS = 150` and `MAX_USER_TOKENS = 250` dead constants from `prompt.py` — they are not enforced anywhere, just misleading.

## Color scheme
- Green markup `[green]` — success: winners, clean parses, circuit closed
- Cyan markup `[cyan]` — LLM in-flight events
- Blue markup `[blue]` — phase transitions, table state
- Yellow (WARNING level) — fallbacks, remapped actions, circuit open
- Red (ERROR level) — crashes

## Tasks

### Task 1: logging_config.py + main.py wiring
Create `backend/app/logging_config.py` with `setup_logging()` using `RichHandler(markup=True, rich_tracebacks=True, show_path=False)`. Suppress `httpx`, `httpcore`, `uvicorn.access` to WARNING. Call `setup_logging()` at the top of the lifespan in `main.py` before any other startup work.

### Task 2: game_loop.py — session boundary logs
On session start: log `[bold cyan]═══ NEW SESSION ═══[/bold cyan]` then one line per player showing name, archetype, chips, model. On session end: log budget summary and final chip counts.

### Task 3: session.py — hand boundary logs
On hand start (inside `run()`): log `[bold blue]── Hand N/M ──[/bold blue]` with dealer name and all stacks. On hand end: log winner name, hand name (or "last standing"), pot won, and updated stacks.

### Task 4: game.py — phase transitions + per-action table
Add `logger = logging.getLogger(__name__)`. At each phase start in `run_hand()`: log `[blue]► PHASE[/blue]  Board: ...  Pot: N`. After each action in `run_betting_round()`: log player name + action + amount (color by action: raise=green, fold=yellow, call/check=white).

### Task 5: decision.py + prompt.py — token budget
- `decision.py`: raise `max_tokens=300` → `max_tokens=5000`; polish existing log markup to match the green/cyan/yellow scheme
- `prompt.py`: remove `MAX_SYSTEM_TOKENS = 150` and `MAX_USER_TOKENS = 250` constants (not enforced, just misleading)
