```python
game.py — single-hand Texas Hold'em engine.

Implements POKER-01 (full Hold'em flow), POKER-02 (action order), POKER-05 (chip tracking).

The decision seam is DecisionFn: async def make_decision(player, game_state) -> Action.

Action order rules:

  2. All active non-all-in players have bet == current_bet

decision function is called for that seat. This prevents the infinite-loop / early-
termination bugs documented in RESEARCH.md Pitfall 1.
```

**Helper: valid_actions(player, state) -> list[ActionType]**
- Compute call_amount = state.current_bet - player.bet
- If call_amount == 0: return ['fold', 'check', 'raise'] if player.chips > 0 else ['fold', 'check']
- If call_amount > 0 and player.chips > call_amount: return ['fold', 'call', 'raise']
- If call_amount > 0 and player.chips <= call_amount: return ['fold', 'call']  (all-in only option)
- fold is always valid; check requires call_amount==0; raise requires chips > call_amount

**Helper: is_round_closed(state, players) -> bool**
- Get active = [i for i, p in enumerate(players) if not p.is_folded]
- If len(active) <= 1: return True  (everyone else folded)
- For each i in active: if i not in state.has_acted: return False
- For each i in active: if players[i].bet < state.current_bet and players[i].chips > 0: return False
- Otherwise: return True

**Helper: _next_active_seat(current, n_players, players) -> Optional[int]**
- Scan clockwise from (current+1); return first seat where not players[i].is_folded
- Return None if no active player found (shouldn't happen if is_round_closed checked first)

**Helper: _collect_bets_to_pot(players, game_state) -> int**
- Sum all player.bet values into pot addition
- Set each player.bet = 0
- Returns new pot value (game_state.pot + sum_of_bets)

**Async function: run_betting_round(game_state, players, dealer_seat, is_preflop, big_blind, decision_fn) -> tuple[GameState, list[Player]]**
- Initialize BettingRoundState(current_bet=big_blind if is_preflop else 0, last_raise_size=big_blind, aggressor_seat=-1, has_acted=set())
- If is_preflop: current_seat = (dealer_seat + 3) % len(players)  [UTG]
- Else: current_seat = find first active starting from (dealer_seat + 1)
- Loop: while not is_round_closed(betting_state, players):
  - If current player is folded: advance current_seat; continue
  - Call decision_fn(players[current_seat], game_state) — await the coroutine
  - Add current_seat to betting_state.has_acted
  - Process action (fold → is_folded=True; call → deduct chips, update bet; raise → deduct chips, update bet, update current_bet, update last_raise_size, set aggressor_seat; check → nothing)
  - For call: deduct min(call_amount, player.chips) — handles all-in
  - For raise: validate amount >= betting_state.current_bet + betting_state.last_raise_size; deduct (amount - player.bet) from chips; set player.bet = amount; update betting_state
  - Update player.action field to the action_type taken
  - Advance to _next_active_seat
  - Check early termination: active count == 1 → break
- Collect bets to pot after round closes
- Reset all player.bet = 0 for next round
- Return updated (game_state, players)

**Async function: run_hand(players, dealer_seat, big_blind, decision_fn) -> GameState**
This is the main entry point. Steps in order:
1. Deep copy players list (do not mutate caller's list)
2. Reset hand-start state: for each player: is_folded=False, bet=0, action=None, is_winner=False, hole_cards=[]
3. Create fresh Deck() and shuffle
4. Post blinds:
   - sb_seat = (dealer_seat + 1) % n
   - bb_seat = (dealer_seat + 2) % n
   - sb_amount = big_blind // 2
   - players[sb_seat].chips -= sb_amount; players[sb_seat].bet = sb_amount
   - players[bb_seat].chips -= big_blind; players[bb_seat].bet = big_blind
   - Do NOT add sb_seat or bb_seat to has_acted — they posted forced bets, not voluntary actions
5. Deal 2 hole cards to each active player (chips > 0):
   - For each active player seat in order: cards = deck.draw(2)
   - Convert to Card models: [Card(**card_display(c)) for c in cards]
   - Assign to player.hole_cards
6. pot = 0 (bets not yet collected — they're in player.bet fields)
   - Actually: pot = sb_amount + big_blind (blind amounts go to pot immediately)
   - Correction: set player.bet tracks their street contribution; pot starts at 0 BEFORE blinds
   - Proper sequence: pot = sb_amount + big_blind; players[sb_seat].chips -= sb_amount; players[bb_seat].chips -= big_blind; player.bet values are NOT set (they're collected into pot)
   
   NOTE: There are two valid approaches — either track player.bet and collect at round end, or collect immediately. RESEARCH.md Pattern uses player.bet to track street contributions and collects at round end. Use the player.bet approach for consistency with the betting round helper.
   
   Correct approach: After posting, sb_seat.bet = sb_amount, bb_seat.bet = big_blind. pot = 0. The betting round will collect bets to pot when it closes. But pre-flop, the BB's bet is already current_bet — this is correct.
   
7. Build initial GameState(phase='pre-flop', pot=0, community_cards=[], players=players, show_cards=False)
8. Pre-flop betting round: run_betting_round(game_state, players, dealer_seat, is_preflop=True, big_blind, decision_fn)
9. Check if only 1 active player — if so, award pot to last standing, return early (no showdown)
10. Deal flop: deck.draw(3) → [Card(**card_display(c)) for c in flop_cards]
11. Update game_state.phase = 'flop', game_state.community_cards = flop_cards
12. Flop betting round
13. Check early termination again
14. Deal turn: deck.draw(1)[0] → add Card to community_cards
15. Update game_state.phase = 'turn'
16. Turn betting round
17. Check early termination again
18. Deal river: deck.draw(1)[0] → add Card to community_cards
19. Update game_state.phase = 'river'
20. River betting round
21. SHOWDOWN:
    - game_state.phase = 'showdown'
    - game_state.show_cards = True
    - For each non-folded player: convert hole_cards + community_cards to treys ints via new_card(c.r, c.s)
    - Call evaluate_hand(hole_ints, board_ints) for each active player
    - Find winner: min(scores.values()); if tie take first (lowest seat index — D-05)
    - Award pot: players[winner_idx].chips += game_state.pot
    - game_state.pot = 0
    - game_state.winner = winner_idx
    - game_state.winner_hand = hand_name from evaluate_hand
    - players[winner_idx].is_winner = True
22. Return final GameState with updated players

```python
async def mock_decision(player: Player, game_state: GameState) -> Action:
    """Mock DecisionFn: always checks if possible, otherwise calls. Phase 4 replaces this."""
    # Reconstruct BettingRoundState from game_state is not possible here — 
    # game.py internal betting state is not stored in GameState.
    # Simple heuristic: if player.bet == current street bet, check; else call.
    # We detect "can check" by looking at player's bet vs others.
    max_bet = max((p.bet for p in game_state.players if not p.is_folded), default=0)
    if player.bet >= max_bet:
        return Action(action_type='check')
    return Action(action_type='call')
```
