**2. Modify run_hand() signature** — add `broadcast_fn: Optional[BroadcastFn] = None` as the last parameter:

```python
async def run_hand(
    players: list[Player],
    dealer_seat: int,
    big_blind: int,
    decision_fn: DecisionFn,
    broadcast_fn: Optional[BroadcastFn] = None,
) -> GameState:
```

**3. Add a private helper function** `_maybe_broadcast` immediately before `run_hand()`:

```python
async def _maybe_broadcast(state: GameState, fn: Optional[BroadcastFn]) -> None:
    """Call broadcast_fn if provided. No-op when fn is None (Phase 2 tests unaffected)."""
    if fn is not None:
        await fn(state)
```

**4. Insert `await _maybe_broadcast(game_state, broadcast_fn)` at 5 phase transition points inside run_hand():**

- After `game_state = GameState(phase="pre-flop", ...)` is built (the initial state construction block) and BEFORE `await run_betting_round(...)` for pre-flop

- After the showdown resolution block sets `game_state.winner`, `game_state.winner_hand`, `game_state.players` but BEFORE `return game_state`

Each insertion looks like:
```python
await _maybe_broadcast(game_state, broadcast_fn)
```
