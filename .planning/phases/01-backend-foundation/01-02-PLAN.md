Key treys facts (from RESEARCH.md, verified against source):
- `Card.new('Ah')` → specific 32-bit int — NEVER construct card ints manually
- `Deck().cards` → list of 52 treys-format ints — use for deck, never range(52)
- `evaluator.evaluate(board, hole)` — README convention: board first, hole second
  Both orderings produce identical scores (method concatenates lists) — use board-first for community convention
- `hand_size_map` keys are 5, 6, 7 only — evaluate() with 2 or 4 total cards raises KeyError
- Score range: 1 (Royal Flush) to 7462 (worst High Card) — LOWER score = STRONGER hand
- `get_rank_class(score)` → int class; `class_to_string(rank_class)` → str like "Royal Flush"

Monte Carlo pattern:
- Build remaining deck: `[c for c in Deck().cards if c not in seen_set]`
- Shuffle remaining, slice for runout board + opponent hole cards
- `cards_to_deal = 5 - len(community_cards)` to complete board to 5 community cards
- Opponent hands start after board cards: `remaining_deck[cards_to_deal + i*2 : cards_to_deal + i*2 + 2]`
- Win condition: `my_score < opp_score` for ALL opponents (lower = better)

Pre-flop guard:
```python
if len(community_cards) < 3:
    return {"hand_strength": None, "hand_name": None}
```

    - Opponent i gets: remaining[cards_to_deal + i*2 : cards_to_deal + i*2 + 2]
    - my_score wins if my_score < ALL opponent scores (lower = stronger in treys)
    - win_probability = wins / n_simulations
    - hand_strength: call evaluate_hand(hole_cards, community_cards)["hand_strength"] — None if pre-flop
    - Returns: {"hand_strength": int|None, "win_probability": float, "pot_odds": None}
