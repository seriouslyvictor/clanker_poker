game_state event — full GameState snapshot, named event (NOT default message event):
```
id: 42

event: game_state

```

reasoning event — streaming delta per (playerId, phase), named event:
```
id: 43
retry: 3000
event: reasoning
data: {"playerId":"gpt4","phase":"pre-flop","delta":"I see a strong","done":false}
```

reasoning_snapshot event — full list of accumulated reasoning deltas sent on connect/reconnect:
```
id: 44
retry: 3000
event: reasoning_snapshot
data: [{"playerId":"gpt4","phase":"pre-flop","delta":"I see a strong hand","done":true}, ...]
```
The data field is a JSON array of ReasoningDelta objects (same shape as individual reasoning events).
The frontend handler replays all deltas in order to rebuild the reasoning state from scratch.

ReasoningDelta shape:
```typescript
interface ReasoningDelta {
  playerId: string   // e.g. "gpt4", "gemini" — matches ModelId
  phase: string      // e.g. "pre-flop", "flop"
  delta: string      // token chunk; empty string on done=true
  done: boolean      // true = final event for this player+phase
}
```

CRITICAL: Use `es.addEventListener('game_state', handler)` NOT `es.onmessage`.
Named SSE events (event: game_state) do NOT fire onmessage — onmessage only handles unnamed events.

Auto-reconnect: Native EventSource reconnects automatically on error.
DO NOT call es.close() in onerror — that stops auto-reconnect.
Only call es.close() in the useEffect cleanup function (return).
Backend sends retry:3000 on every event — browser uses this for reconnect timing.
Backend sends full game_state snapshot + reasoning_snapshot on every connect — including reconnects.

**Step 2 — Create frontend/src/hooks/useGameStream.ts**:

```typescript
import { useEffect, useRef, useState } from 'react'
import type { GameState, ReasoningEntry } from '../components/types'

export type ConnectionState = 'connecting' | 'open' | 'closed'

export interface GameStream {
  gameState: GameState | null
  reasoning: ReasoningEntry[]
  connectionState: ConnectionState
}

interface ReasoningDelta {
  playerId: string
  phase: string
  delta: string
  done: boolean
}

// URL normalization: new URL('/api/stream', base) prevents double-slash
// if VITE_API_URL is set with a trailing slash (e.g. "http://localhost:8000/").
const _base = import.meta.env.VITE_API_URL ?? 'http://localhost:8000'
const SSE_URL = new URL('/api/stream', _base).toString()

/**
 * Apply a single ReasoningDelta to the current reasoning entry array.
 * If an entry for (playerId, phase) already exists, concatenate the delta text.
 * If not, create a new entry.
 * Returns a new array (immutable update).
 */
function applyDelta(prev: ReasoningEntry[], delta: ReasoningDelta): ReasoningEntry[] {
  const idx = prev.findIndex(
    r => r.playerId === delta.playerId && r.phase === delta.phase
  )
  if (idx !== -1) {
    const updated = [...prev]
    updated[idx] = {
      ...updated[idx],
      text: updated[idx].text + delta.delta,
      streaming: !delta.done,
    }
    return updated
  }
  const entry: ReasoningEntry = {
    id: `${delta.playerId}-${delta.phase}-${Date.now()}`,
    playerId: delta.playerId as ReasoningEntry['playerId'],
    phase: delta.phase,
    text: delta.delta,
    streaming: !delta.done,
    action: null,
    amount: 0,
  }
  return [...prev, entry]
}

export function useGameStream(): GameStream {
  const [gameState, setGameState] = useState<GameState | null>(null)
  const [reasoning, setReasoning] = useState<ReasoningEntry[]>([])
  const [connectionState, setConnectionState] = useState<ConnectionState>('connecting')
  const prevWinnerRef = useRef<number | null | undefined>(undefined)

  useEffect(() => {
    const es = new EventSource(SSE_URL)

    // onopen: fires on initial connect AND after every auto-reconnect.
    // Without this, connectionState stays 'connecting' even after a successful reconnect.
    es.onopen = () => {
      setConnectionState('open')
    }

    es.addEventListener('game_state', (e: MessageEvent) => {
      try {
        const state: GameState = JSON.parse(e.data as string)

        // Clear reasoning when a new hand starts:
        // winner transitions from non-null → null (game reset after WINNER phase).
        if (
          prevWinnerRef.current !== null &&
          prevWinnerRef.current !== undefined &&
          state.winner === null
        ) {
          setReasoning([])
        }
        prevWinnerRef.current = state.winner

        setGameState(state)
      } catch (err) {
        console.error('[useGameStream] Failed to parse game_state event:', err)
      }
    })

    es.addEventListener('reasoning', (e: MessageEvent) => {
      try {
        const delta: ReasoningDelta = JSON.parse(e.data as string)
        setReasoning(prev => applyDelta(prev, delta))
      } catch (err) {
        console.error('[useGameStream] Failed to parse reasoning event:', err)
      }
    })

    // reasoning_snapshot: sent by backend on every connect (including reconnects).
    // Contains all accumulated reasoning deltas for the current hand phase.
    // Replay all deltas in order to rebuild reasoning state — prevents reasoning loss on reconnect.
    es.addEventListener('reasoning_snapshot', (e: MessageEvent) => {
      try {
        const deltas: ReasoningDelta[] = JSON.parse(e.data as string)
        // Rebuild reasoning from scratch using the snapshot — do not merge with stale state.
        // The snapshot is the authoritative accumulated state from the backend Redis list.
        setReasoning(() => {
          let rebuilt: ReasoningEntry[] = []
          for (const delta of deltas) {
            rebuilt = applyDelta(rebuilt, delta)
          }
          return rebuilt
        })
      } catch (err) {
        console.error('[useGameStream] Failed to parse reasoning_snapshot event:', err)
      }
    })

    es.onerror = () => {
      setConnectionState('connecting')
      // DO NOT call es.close() here — native EventSource auto-reconnects.
      // Calling close() in onerror stops auto-reconnect entirely.
      // The browser uses retry:3000 (sent by backend) to time the reconnect.
      // On reconnect, backend resends game_state snapshot + reasoning_snapshot.
    }

    return () => {
      // Cleanup only: close on component unmount
      es.close()
      setConnectionState('closed')
    }
  }, []) // empty deps — single EventSource lifetime per component mount

  return { gameState, reasoning, connectionState }
}
```

Key implementation notes:
- `SSE_URL` uses `new URL('/api/stream', _base)` — safe against trailing slash in VITE_API_URL
- `es.onopen` sets connectionState to `'open'` on initial connect AND after every auto-reconnect
- `applyDelta` helper extracted for reuse across `reasoning` and `reasoning_snapshot` handlers
- `reasoning_snapshot` rebuilds reasoning from scratch (not merge) — the backend snapshot is authoritative
- `prevWinnerRef` tracks the previous `winner` value to detect new-hand transition (null after non-null)
- `try/catch` around all JSON.parse calls — malformed SSE data logs error, does not crash
- Empty dependency array `[]` on useEffect — single EventSource lifetime per component mount

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FastAPI SSE → EventSource | SSE data crosses network into browser; must be treated as untrusted |
| SSE JSON → React state | JSON.parse output flows into React state and ultimately DOM rendering |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Tampering | JSON.parse of SSE event data | mitigate | game_state, reasoning, and reasoning_snapshot parse calls are all wrapped in try/catch; malformed data logs error and returns without updating state — app does not crash |
| T-05-03-02 | Spoofing | XSS via SSE data rendered to DOM | mitigate | React renders all string values as text nodes (not innerHTML); reasoning text rendered in a `<div>` with children — not dangerouslySetInnerHTML — no XSS vector |
| T-05-03-03 | Denial of Service | EventSource connecting to wrong URL in production | mitigate | SSE_URL built with `new URL('/api/stream', base)` where base comes from `import.meta.env.VITE_API_URL` with localhost:8000 fallback; production deployment must set VITE_API_URL |
| T-05-03-04 | Repudiation | Reasoning text duplicated after reconnect | mitigate | `reasoning_snapshot` handler rebuilds state from scratch (not merge with stale); `applyDelta` deduplicates by (playerId, phase) within the snapshot replay |
| T-05-03-05 | Tampering | reasoning_snapshot contains unexpected large payload | accept | Payload originates from Redis list populated only by the backend publisher; no external write path exists; Redis is localhost-only |
</threat_model>
