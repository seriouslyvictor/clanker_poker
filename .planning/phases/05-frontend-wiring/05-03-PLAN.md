ReasoningDelta shape:
```typescript
interface ReasoningDelta {
  playerId: string   // e.g. "gpt4", "gemini" — matches ModelId
  phase: string      // e.g. "pre-flop", "flop"
  delta: string      // token chunk; empty string on done=true
  done: boolean      // true = final event for this player+phase
}
```

CRITICAL: Use `es.addEventListener('game_state', handler)` NOT `es.onmessage`.
Named SSE events (event: game_state) do NOT fire onmessage — onmessage only handles unnamed events.

Auto-reconnect: Native EventSource reconnects automatically on error.
DO NOT call es.close() in onerror — that stops auto-reconnect.
Only call es.close() in the useEffect cleanup function (return).
Backend does NOT replay by Last-Event-ID — it sends a full snapshot on every connect.

**Step 2 — Create frontend/src/hooks/useGameStream.ts**:

```typescript
import { useEffect, useRef, useState } from 'react'
import type { GameState, ReasoningEntry } from '../components/types'

export type ConnectionState = 'connecting' | 'open' | 'closed'

export interface GameStream {
  gameState: GameState | null
  reasoning: ReasoningEntry[]
  connectionState: ConnectionState
}

interface ReasoningDelta {
  playerId: string
  phase: string
  delta: string
  done: boolean
}

const SSE_URL = import.meta.env.VITE_API_URL
  ? `${import.meta.env.VITE_API_URL}/api/stream`
  : 'http://localhost:8000/api/stream'

export function useGameStream(): GameStream {
  const [gameState, setGameState] = useState<GameState | null>(null)
  const [reasoning, setReasoning] = useState<ReasoningEntry[]>([])
  const [connectionState, setConnectionState] = useState<ConnectionState>('connecting')
  const prevWinnerRef = useRef<number | null | undefined>(undefined)

  useEffect(() => {
    let es: EventSource

    function connect() {
      es = new EventSource(SSE_URL)
      setConnectionState('connecting')

      es.addEventListener('game_state', (e: MessageEvent) => {
        try {
          const state: GameState = JSON.parse(e.data as string)
          setConnectionState('open')

          // Clear reasoning when a new hand starts:
          // winner transitions from non-null → null (game reset after WINNER phase)
          if (prevWinnerRef.current !== null && prevWinnerRef.current !== undefined && state.winner === null) {
            setReasoning([])
          }
          prevWinnerRef.current = state.winner

          setGameState(state)
        } catch (err) {
          console.error('[useGameStream] Failed to parse game_state event:', err)
        }
      })

      es.addEventListener('reasoning', (e: MessageEvent) => {
        try {
          const delta: ReasoningDelta = JSON.parse(e.data as string)
          setReasoning(prev => {
            const idx = prev.findIndex(
              r => r.playerId === delta.playerId && r.phase === delta.phase
            )
            if (idx !== -1) {
              // Accumulate delta text onto existing entry
              const updated = [...prev]
              updated[idx] = {
                ...updated[idx],
                text: updated[idx].text + delta.delta,
                streaming: !delta.done,
              }
              return updated
            }
            // New (playerId, phase) pair — create entry
            const entry: ReasoningEntry = {
              id: `${delta.playerId}-${delta.phase}-${Date.now()}`,
              playerId: delta.playerId as ReasoningEntry['playerId'],
              phase: delta.phase,
              text: delta.delta,
              streaming: !delta.done,
              action: null,
              amount: 0,
            }
            return [...prev, entry]
          })
        } catch (err) {
          console.error('[useGameStream] Failed to parse reasoning event:', err)
        }
      })

      es.onerror = () => {
        setConnectionState('connecting')
        // DO NOT call es.close() here — native EventSource auto-reconnects.
        // Calling close() here would stop auto-reconnect entirely.
        // The browser sends Last-Event-ID on reconnect; backend sends full snapshot.
      }
    }

    connect()

    return () => {
      // Cleanup only: close on component unmount
      es.close()
      setConnectionState('closed')
    }
  }, []) // empty deps — connect once on mount

  return { gameState, reasoning, connectionState }
}
```

Key implementation notes:
- `prevWinnerRef` tracks the previous `winner` value to detect the null→non-null→null cycle
- `try/catch` around both JSON.parse calls — malformed SSE data logs an error but does not crash
- `playerId` cast to `ReasoningEntry['playerId']` (which is `ModelId`) — TypeScript strict mode requires this
- Empty dependency array `[]` on useEffect — single EventSource lifetime per component mount

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FastAPI SSE → EventSource | SSE data crosses network into browser; must be treated as untrusted |
| SSE JSON → React state | JSON.parse output flows into React state and ultimately DOM rendering |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Tampering | JSON.parse of SSE event data | mitigate | Both game_state and reasoning parse calls are wrapped in try/catch; malformed data logs error and returns without updating state — app does not crash |
| T-05-03-02 | Spoofing | XSS via SSE data rendered to DOM | mitigate | React renders all string values as text nodes (not innerHTML); the `e.text` field in ReasoningPanel is rendered in a `<div>` with children — not dangerouslySetInnerHTML — so no XSS vector exists |
| T-05-03-03 | Denial of Service | EventSource connecting to wrong URL in production | mitigate | SSE_URL uses `import.meta.env.VITE_API_URL` with localhost fallback; production deployment must set VITE_API_URL to the correct backend URL |
| T-05-03-04 | Repudiation | Reasoning text accumulated incorrectly (duplication) | mitigate | `findIndex` by (playerId, phase) deduplicates — same pair concatenates, new pair appends; done=true sets streaming=false |
</threat_model>
