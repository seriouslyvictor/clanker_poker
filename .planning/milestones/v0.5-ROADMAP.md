# Milestone v0.5: MVP — LLM Poker Arena

**Status:** ✅ SHIPPED 2026-05-14
**Phases:** 1–6
**Total Plans:** 24

## Overview

Complete end-to-end LLM poker arena: four AI models compete at Texas Hold'em in a Balatro-styled browser experience. Viewers watch a shared real-time game via SSE, can start games on demand, and stake anonymous predictions on who wins. Every component — poker engine, LLM orchestration, SSE broadcast, Vite SPA, viewer interaction — is built and human-UAT'd.

## Milestone Summary

**Key Decisions:**
- Backend: Python (FastAPI) over Node.js — LiteLLM ecosystem and native async streaming
- Architecture: FastAPI → Redis pub/sub → SSE → Vite SPA (no Next.js API routes, no serverless)
- LLM role: narration + decision selection only; all math computed programmatically
- Frontend migration: Next.js → Vite (components were already pure React, no SSR used)
- Game trigger: viewer-initiated demand gate enforced server-side
- Sequential LLM calls (not parallel) to start — simpler, cheaper
- Predictions: localStorage only (no backend persistence in v1)
- Poker rules: single main pot, no side pots — simplified for v1

**Issues Resolved:**
- BB gets-option bug (has_acted tracking in game.py)
- asyncio_mode=strict required for pytest-asyncio
- .gitignore blocking .env.example (negation rule)
- LiteLLM timeout tuned to 45s for slow models
- Phase string case mismatch (frontend vs backend)
- Prediction widget zIndex conflict with winner overlay
- Tweaks button relic overlay
- server.fs.allow cross-root import for models.config.json

**Issues Deferred:**
- Live viewer count display (v2)
- Scheduled game intervals (v2)
- Prediction streak tracking (v2)
- Pre-game lobby with countdown (v2)
- Side pots / all-in handling (v2)
- Game history and replay — PostgreSQL (v2)

**Technical Debt Incurred:**
- 503 demand-gate path not tested in local dev (UAT item skipped)
- LLM timeout is 45s global; per-call timeout may need tuning in production
- Configurable hands-per-session deferred (todo logged)
- Optional archetypes mode deferred (todo logged)
